# 🔬🔋 Експерименти із заряджання та автономності акумуляторів

**Версія:** 1.4.4  
**Дата:** 25.10.2026  
**Тип:** прогресивний вебзастосунок (PWA) для Android та інших пристроїв.

## Опис
Це електронний лабораторний журнал для дослідів із заряджання батарей і тривалості роботи пристроїв від акумулятора. Можна створювати, переглядати, редагувати, завершувати та видаляти записи без облікового запису чи сервера.

[Відкрити застосунок](https://bitschips.github.io/ejercicios_html/experimentos/).

> **Мова інтерфейсу:** кнопки самого застосунку наразі англійською. Цей посібник перекладено українською; дані експериментів і файли XML не змінюються залежно від мови посібника.

## Вкладки Charging та Autonomy
- **Charging (Заряджання):** записуйте хімічний тип батареї, її формат, номінальну ємність (мА·год), ідентифікацію, початкову напругу (В), напругу заряджання (В), струм заряджання (мА), час початку та завершення, кінцеву напругу й примітки.
- **Autonomy (Автономність):** визначайте, скільки працює пристрій або лампа від батареї. Записуйте пристрій, характеристики батареї, початкову й кінцеву напругу та час початку й завершення. Тривалість обчислюється автоматично.

Старі записи вважаються дослідами заряджання. Обидва типи зберігаються в резервній копії XML.

## Як користуватися
1. Відкрийте застосунок та виберіть **Charging** або **Autonomy**.
2. Натисніть **+**, щоб створити експеримент.
3. Введіть характеристики батареї та вимірювання. Натисніть **Save (Зберегти)**.
4. Щоб завершити дослід, розгорніть картку та натисніть **Edit / finish (Редагувати / завершити)**. Введіть час завершення й кінцеву напругу та збережіть.
5. Для перегляду результатів, приміток і кнопок редагування або видалення натисніть на картку.

**In progress** означає «Триває» (червона позначка), **Completed** — «Завершено» (зелена). Дати відображаються у форматі день/місяць/рік.

## Розрахунки
Для завершеного досліду застосунок показує тривалість. Якщо під час заряджання зазначено струм, приблизний заряд обчислюється за формулою:

**мА·год = мА × години**

Формула припускає постійний струм. Це **не** виміряна фактична ємність акумулятора та **не** оцінка ефективності заряджання.

Для автономності за наявності ємності та робочого струму може відображатися теоретична тривалість: **години = ємність (мА·год) / струм (мА)**. Реальна тривалість залежить від умов використання.

## Картки експериментів
У згорнутій картці показано номер досліду, назву батареї або пристрою, фотографію (якщо додана), стан, дату та тривалість (якщо дослід завершено). Розгорніть картку, щоб переглянути напругу, струм, орієнтовний заряд, примітки та дії.

Для **Charging** показано назву батареї або її хімічний тип, формат і ємність. Для **Autonomy** — «Пристрій @ Батарея».

## Фотографії
До кожного експерименту можна додати **одну фотографію**. У формі виберіть **Experiment photo**, зробіть знімок або виберіть наявний. Для видалення натисніть **Remove photo**. Зображення автоматично зменшується до **800 пікселів** за довшою стороною та стискається як JPEG із якістю **55 %**.

Фотографії зберігаються локально разом із записами та включаються до XML як дані JPEG у Base64. Старі резервні копії без фотографій також підтримуються.

## Тип і формат батареї
Доступні формати: **AAA, AA, A, Sub-C, C, D, 9 V (PP3), 18650, 21700, 26650, Button cell, Rechargeable button cell, CR2032, Prismatic, Pouch, Other**. Формат батареї не залежить від її хімічного типу та ємності. Поле **Battery identification** допомагає відрізняти батареї, наприклад «акумулятор старого шурупокрута».

## Зв'язок автономності із завершеним заряджанням
Під час створення або редагування експерименту **Autonomy** можна вибрати завершений дослід заряджання. Відображаються лише завершені заряджання, починаючи з найновіших. Хімічний тип, формат, ємність та ідентифікація батареї копіюються; кінцева напруга заряджання стає початковою напругою автономності. Усі скопійовані значення можна змінити.

Виберіть **None — Enter details manually**, щоб заповнити поля самостійно. Зв'язок зберігається під час експорту й імпорту XML.

## Зберігання та резервні копії
Записи й фотографії зберігаються в **localStorage браузера**, а не на GitHub чи сервері. Зазвичай вони залишаються після закриття браузера, але можуть зникнути після очищення даних сайту, видалення браузера або скидання телефона. Очищення лише кешованих файлів зазвичай не видаляє localStorage.

- **Export XML (Експорт XML):** завантажує резервну копію всіх експериментів разом із фотографіями.
- **Import XML (Імпорт XML):** відновлює дані. **MERGE** додає записи без дублювання ідентифікаторів; **REPLACE** замінює всі локальні записи.

**Перед REPLACE обов'язково експортуйте резервну копію.** Зберігайте XML на іншому пристрої або в хмарному сховищі. Між телефонами дані автоматично не синхронізуються.

## Встановлення та офлайн-режим
Відкрийте https://bitschips.github.io/ejercicios_html/experimentos/ у Chrome. Застосунок можна додати на головний екран. Після першого відкриття service worker кешує ресурси для роботи без інтернету. Через кеш оновлення можуть з'являтися із затримкою. Для відкриття посібника на GitHub потрібен інтернет.
